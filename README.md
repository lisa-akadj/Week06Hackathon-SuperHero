# Hackathon Project - Using react for a superhero API

This project utilises the following API:
https://www.superheroapi.com/

## How to use:
### Set up
1. Clone this repo to your local machine.
2. In the terminal, make sure you cd(CHANGE DIRECTORY) into the directory of this repo.  
3. Open this project in your code editor (I would use `code .` if that helps...)
4. In the terminal, run `npm install` to install dependencies. 
5. Go to the https://www.superheroapi.com/
6. Scroll down to the "Login with Github" button.
7. CLICK on the button and do what it asks. 
8. You should have your API token. 
9. Create a ".env" file in THE SAME LEVEL AS package.json 
10. Inside the .env file, type in `VITE_SUPERHERO_TOKEN` followed by `=` followed by your API token. NO SPACES!
11. Run `npm run dev` in your terminal
12. Copy and paste the 'localserver' URL in a browser.
